# sharksnationbaseball.com

Static site for Midwest Sharks / Sharks Nation, hosted free on GitHub Pages.

- `index.html` – the whole site (Teams, About, Join, Donate, Contact)
- `donate/`, `teams/`, `about-us/`, `contact-us/`, `openings/`, `payments/` – keep old links (and the sponsor letters that point to /donate) working
- `CNAME` – tells GitHub Pages to serve sharksnationbaseball.com

To edit: open index.html on github.com, click the pencil, change text, Commit. Live in about a minute.
